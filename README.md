# VLM-RSI

真实视频上的时空图监督与视频模型自进化研究。当前工作线：**建图 → 基于证据出题 → 比较图伪标签与多数投票 → 训练验证**。

**当前状态：推理与数据交付已完成；图标签尚未显示整体优势；v3 和新训练实验待完成。** 当前图是 STEP 风格的部分重实现，事件选择题使用自定义出题协议，不是 STEP 官方完整复现。

## 快速开始

需要 Python 3.9 或以上；基础评分只用标准库，不需要 GPU、模型权重或额外安装依赖。

```bash
git clone https://github.com/heyunkang-pku/VLM-RSI.git
cd VLM-RSI
python3 scripts/score_v2.py
```

该命令从仓库内的冻结题目、原投票统计与单人审核表复算，输出到被 Git 忽略的 `runs/v2-review/`。归档结果保留在 `results/`。

若要查看画面、复核图事实或校验 320 张帧，需要另行获取完整数据包，见 [数据获取](docs/DATA.md)。取得后可运行：

```bash
python3 scripts/score_v2.py --data artifacts/STEP_EVENT_MCQ_V2_DATA.zip --verify-frames
```

## 已有结果

| 指标 | v2 结果 |
|---|---:|
| 视频 / 公共有序帧 | 10 / 320 |
| 冻结选择题 / 原始采样 | 26 / 260 |
| 单人审核可评分题 | 17/26 |
| 图与多数票共同作答题 | 16 |
| 共同题：图标签正确 | 8/16（50%） |
| 共同题：多数票正确 | 10/16（62.5%） |

这是已参与开发的小样本、单人审核结果。全体可评分 17 题上，图标签 8 对 9 错；多数票 10 对 6 错 1 弃权。图与多数票的 48% 一致率不等于准确率。详见 [原始报告](reports/STEP_EVENT_MCQ_V2_REPORT.md) 和 [后续审核结果](results/README.md)。

## 目录

| 路径 | 内容 |
|---|---|
| `docs/` | 交接、协议、数据获取、任务与来源索引 |
| `baseline/v2/` | 冻结题目、投票对照及帧清单 |
| `annotations/` | 已有单人审核原表 |
| `results/` | 交接时的冻结复算结果及说明 |
| `scripts/` | 可移植的 CPU 评分入口 |
| `reports/` | 历史运行报告，保留当时的版本和结论 |
| `legacy_src/` | 原 `20d5065` 源码快照；含旧路径和配置，使用前须适配 |

`artifacts/`、`runs/`、模型权重和媒体默认不进入 Git。原始 MP4、完整环境与训练工程不包含在本仓库。

## 当前目标

改善图事实、事件绑定和出题依据；在独立留出视频上比较标签正确率、覆盖率及有效产量；之后用同一起点和匹配训练量检验训练收益。教师 harness 与可学习增量是相关探索，不属于此次建图交接的必做范围。
