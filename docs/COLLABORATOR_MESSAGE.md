# 可直接发给合作方的说明

这条线想交给你继续牵头：在真实视频上做时空图与图引导 QA，验证它能否提供比 Video-Zero 多数投票更可靠的训练伪标签，随后训练看是否有收益。

目前已跑通 10 段视频的建图适配、26 道自动事件选择题和 260 次同题同帧作答，图、引用、原 32 帧、原始票型、源码和审核包都有。现有图仍是 STEP 风格 partial 重实现，v2 出题是自定义文本协议，不能叫完整 STEP 官方复现。

已有单人审核：26 题只有 17 题可评分；双方共同作答的 16 题里，图标签 8 对，多数票 10 对，所以现在还没有证明图监督更好。已发现图遗漏动作、问题超出证据、选项重叠等问题。

先请你复核交接中的几个失败例子，然后按“先选明确事实关系，再写题和干扰项”改出题；按实际缺口补图与事件绑定。新题冻结后，在留出视频上同题同帧比较图标签与十票，报告正确率、覆盖率及有效产量。最后做同一起点、同题库、同训练量的 Graph/Vote 训练对照。

README 和 docs/HANDOFF.md 给了阅读入口、当前结果、源码位置和后续验收目标；artifacts 有完整 v2 数据与独立盲审包。教师 harness/可学习增量是另一条正在探索的线，不需要你先把整套 agent 做出来。
